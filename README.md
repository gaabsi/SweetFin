# SweetFin

Client iOS et tvOS non officiel pour [Jellyfin](https://jellyfin.org), basé sur [Swiftfin](https://github.com/jellyfin/Swiftfin).

Pensé pour fonctionner avec le plugin serveur EnhancedFin (notes, watchlist, suivi, calendrier).
